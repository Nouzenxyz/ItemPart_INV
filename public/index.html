Import inventory

Drop your inventory Excel file here, exactly as it is. It is checked first, and nothing is saved until you press Save import.

Each row is matched to a line by model, part code, description and location. A match only has its quantity updated, anything else is added as a new line, and nothing is ever deleted.

Backup & restore

Backups protect inventory and transaction history if the server or database is damaged.

Create a backup

Automatic backups run every six hours on the server. Admins can also create one now and download it for safekeeping.

Backup fileDate createdSize

Restore a backup

  1. Stop the inventory app on the server so the database is not in use.
  2. Make a separate copy of the current data/inventory.db before replacing anything.
  3. Download the selected backup and copy it into the server’s data folder as inventory.db.
  4. Start the app and check the stock, users, and transaction history.

A restore returns the system to the backup date. Transactions recorded after that backup will not be in the restored database.

Quick help

Guidance for common tasks in the inventory app.

1

Find a part

  1. Open Parts.
  2. Search by model, part code, or description.
  3. Select a part row to see its quantity at each location.
2

Receive or issue stock

  1. On Parts, choose Receive stock or Issue stock.
  2. Search and add each part and enter its quantity.
  3. Review the items and details, then confirm to save. The receipt shows previous quantity and new total.
3

Record a repair

  1. Open Repairs and choose New repair job.
  2. Enter the appliance model and any serial number or problem details.
  3. Use Stock Out for repair on the job to link parts issued to it.
4

Check transactions and reports

  1. Open Transactions and search a stock or requisition number.
  2. Select a transaction number to view or print its receipt.
  3. Use Reports for repair trends and restock priorities.
5

Import or export a spreadsheet

  1. Open Import / Export.
  2. Choose the Excel file and review the check results.
  3. Save the import only after checking the rows and warnings.
6

Count stock

  1. Open Physical count from the navigation and choose a location.
  2. Enter the quantity actually counted and a reason for any difference.
  3. Review the old and counted amounts before posting adjustments.
7

Prepare a restock order

  1. In Reports, open Restock priorities and select parts.
  2. Check the suggested quantities, then create a purchase draft.
  3. Mark it ordered. Use Receive stock as deliveries arrive; partial receipts are allowed.
8

Back up data

  1. Admins can create and download a backup under Backup & restore in the navigation.
  2. Automatic backups also run on the server every six hours.
  3. To restore, stop the server first and follow the steps on the Backup & restore page.
